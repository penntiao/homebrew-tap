# penntiao/homebrew-tap

Homebrew tap for apps by [@penntiao](https://github.com/penntiao).

```bash
brew install --cask penntiao/tap/smolder
```

| Cask | What it is |
|---|---|
| [`smolder`](https://github.com/penntiao/smolder) | Menu bar thermal watchdog for always-on, lid-closed Apple Silicon Macs |

```bash
brew install penntiao/tap/smolder-unlock
```

| Formula | What it is |
|---|---|
| [`smolder-unlock`](https://github.com/penntiao/smolder/tree/main/unlock) | Installer for Smolder Unlock: bring a FileVault Mac back after a restart, from your phone |
