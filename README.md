# penntiao/homebrew-tap

Homebrew tap for apps by [@penntiao](https://github.com/penntiao).

```bash
brew install --cask penntiao/tap/smolder
```

| Cask | What it is |
|---|---|
| [`smolder`](https://github.com/penntiao/smolder) | Menu bar thermal watchdog for always-on, lid-closed Apple Silicon Macs |
